# シナリオ作成スクリプト(tools/scenario-src)

`scenarios/*.json` のうち、手で座標を設計したシナリオの「元データ」です。
選手 16 人の座標を **5 ステップ分の表**(1 行 = 1 選手、5 列 = Step 1〜5)で書き、`lib.mjs` の `build()` で v2 スキーマの JSON に変換します。

## 使い方
```bash
npm run scenarios          # 全スクリプトを実行して scenarios/ を作り直す
npm run scenarios:check    # スクリプトと scenarios/ が一致しているか確認(CI でも実行)
npm run validate           # できた JSON の検証(オフサイド・速さ・重なり・漢字など)
```

## 直し方
- 座標・文章・吹き出しなどを変える時は、**JSON ではなくこのフォルダのスクリプトを直して** `npm run scenarios` で作り直す(JSON だけ直すと `scenarios:check` が失敗する)。
- 表の書き方: `h7 6,24 7,21 5,9 4,7 5,7` = 味方 7 番の Step 1〜5 の座標(X,Y)。
- よくあるミス側の `steps` で `null` にしたステップは、お手本の同じステップ(文章・ボール・オーバーレイ)を使う。Step 1 は必ずお手本と同じになる。
- 同じテーマの別パターンは、先に作った JSON から `title`・`theme` などを読みこむ(`groupOf()`)。そのため `build-all.mjs` の順番で実行する。
- 疑問形タイトル・合言葉・おすすめの順番・ルールの注記・練習メニューは `groups.mjs` から自動で入る。新しいテーマを作る時は、先に `groups.mjs` に追加する。

## ファイル
| ファイル | 内容 |
|---|---|
| `lib.mjs` | 座標表 → JSON の変換と、オーバーレイ・ボールの書き方の補助(`formation: "2-3-2"` で味方を 2-3-2 にできる)。練習メニューは `buildDrill()` と `cone` / `gate` / `foot` |
| `groups.mjs` | テーマ単位の値(疑問形タイトル・合言葉・おすすめの順番・ルールの注記・練習メニュー)。同じテーマのパターンで値がずれないよう、ここだけで管理する |
| `00-box-entry-left.mjs` | 最初のシナリオ(サイドからゴール前へ:左サイドから) |
| `w1-*.mjs` | 第 1 弾(取られたらすぐ取り返す / 1人が行く、1人がカバー / パスコースに顔を出そう / 相手の後ろへ走るタイミング) |
| `w2-*.mjs` | 第 2 弾(取ったら前を見よう / ワンツー / ゴール前はボールと相手の両方を見る / ゴールキック) |
| `w3-*.mjs` | 第 3 弾(残り 9 テーマと、既存テーマへの追加パターン) |
| `w3-box-entry-right.mjs` | 左サイドのシナリオを左右反転して「右サイドから」を作る |
| `w4-box-entry-byline.mjs` | 第 4 弾(サイドからゴール前へ:ゴールライン近くから) |
| `w5-*.mjs` | 第 5 弾(もらう前に周りを見よう / 2対1は引きつけてからパス / 数で負けている時はおくらせる / ボールの反対側はしぼろう / 味方のコーナーキック) |
| `w6-*.mjs` | 第 6 弾(1対1でしかけよう / 打てる時はシュート) |
| `w7-formation-232.mjs` | 2-3-2 版(B1・C1・D1・E1)。3-3-1 のシナリオの文章・ボールを使い、4番を外して10番を加え、置きかえる選手の座標だけを書く |
| `w8-*.mjs` | ポジション別の場面(BL-23)。`gk`(飛び出し・1対1)/ `cb`(前で取る・外へ大きく)/ `sb`(ななめの構え)/ `cm`(間で受ける・はね返りを拾う)/ `wm`(広がって待つ・ゴール前を見て決める・ついてもどる)/ `fw`(道をふさいで近づく) |
| `w9-*.mjs` | 第 9 弾(BL-26)。`throw-in-defense`(相手のスローインの守り。E2 を 180° 回して作成)/ `free-kick`(相手のフリーキックの守り・味方のフリーキック。E8 は E9 を 180° 回して作成)/ `open-body`(体をひらいて受けよう)/ `pass-and-move`(パスしたら動こう)/ `double-team`(2人ではさもう) |
| `p-*.mjs` | 練習メニュー(`kind: drill`。`buildDrill()` で作る。座標は `area` の中、出てくる人だけを表に書き、コーン・門は `props`、足の使い方は各ステップの `foot`)。`dribble-zigzag`(D1 ジグザグドリブル) |
| `build-all.mjs` | 上の順番で全部を実行する(`--check` で一致確認) |

LLM で作ったシナリオ(`docs/scenario-prompt.md` の流れ)は、このフォルダにスクリプトがなくても構いません。`scenarios:check` はスクリプトがあるシナリオだけを比べます。
