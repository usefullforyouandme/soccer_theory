## 1. 見方

| 欄 | 意味 |
|---|---|
| 優先度 | **P1** = 子どもの理解・教材としての正しさに直結。次に着手する / **P2** = 教材の質を上げる。P1 の後 / **P3** = あると良い。時期は未定 |
| 種類 | **データ** = `tools/scenario-src/` のスクリプト修正で済む / **新規** = シナリオの追加 / **ビューア** = `src/` の機能追加・画面変更 / **スキーマ** = `schema/` と作成プロンプトの変更を伴う / **検証** = `scripts/validate.mjs` の強化 / **運用** = 実機確認・試用・ドキュメント |
| 出どころ | CR-n = `docs/COACH_REVIEW.md` の指摘 / SPEC = 仕様書 12 章にあった項目 / CAT = カタログ 9 章の候補 |
| 完了条件 | 「終わった」と言える状態を 1 行で書く |

依存関係のあるものは「進め方」欄に書く。P1 はデータ修正が中心で、1 日でまとめて直せる量にしてある。
