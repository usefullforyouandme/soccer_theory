作成日: 2026-11-15 / 対象: 小学4年生(`targetGrade: "middle"`)/ ステータス: 第 1〜6 弾と 2-3-2 版の全 58 本作成済み(25 テーマ。2026-11-15)。2026-11-15 方針決定: オフサイドは必要/シュートコース表示を追加/結末に「残念」を追加(いずれも実装済み)

シナリオを作る前の「設計図」。各シナリオは `docs/SPEC.md` 5 章の学習設計(予想 → お手本 → ミスと比較 → まとめ、1 シナリオ 1 論点)に従う。
ここに書いた「問いかけ」「今日のポイント」「流れ」を `docs/scenario-prompt.md` のテーマ欄に入れて JSON を作る。

## 1. 精査の方針

| 観点 | 方針 |
|---|---|
| 学年に合うか | 4 年生(U-10)では、**2〜3 人の関係(グループ戦術)と、ボールを持っていない時の判断**を中心にする。チーム全体の約束ごと(ライン全体の上げ下げなど)は高学年向けに回す。 |

## 2. テーマとパターンの考え方(2026-11-15 見直し)

同じ「ボールを運ぶ」「守る」でも、**ボールの位置(サイドか中央か、自陣か相手陣か)や守備の状況**で、正しい動き方も、ミスした時の結末も大きく変わる。そこで 1 つのテーマ(`group`)を、状況の違う複数の**パターン**(`pattern`)に分けて作る。

| 用語 | 意味 | データ |
|---|---|---|
| 種類 | ボールを前へ運ぶ / ゴールをねらう / ボールを取る・守る / 切りかえ / リスタート・キーパー | `category` |
| テーマ | 学ぶ原則(例: 取られたらすぐ取り返す)。同じテーマのパターンは同じタイトル | `group`, `title` |
| パターン | ボールの位置・守備の状況の違い(例: サイドで取られた時/中央で取られた時) | `pattern`, `id` |

パターンの分け方:
- **原則は同じで、やり方が変わるもの**を別パターンにする(例: サイドではタッチラインを利用して追いこむ、中央では前後からはさむ)。
- 1 テーマにつき **2 パターンを基本**とし、必要なら 3 つ目を足す。
- パターンごとに「今日のポイント」を変えてよい(例: A1 サイドは「ななめの位置でもらおう」)。ただし同じテーマの原則と矛盾させない。
- 画面では、一覧で「おすすめの順番」または「種類 → テーマ → パターン」の順に並べ、再生画面の「パターン」ボタンで同じテーマの別パターンへ切りかえられる。
- 基本は 3-3-1 で描く。主要なテーマ(B1・C1・D1・E1)には、2-3-2 のチームで描いたパターン(「2-3-2で(〜)」)も用意し、テーマの最後に並べる(指導者レビュー CR-12)。

### 2.1 合言葉とおすすめの順番(2026-11-15。指導者レビュー CR-9・CR-32)

場面ごとの「今日のポイント」は、それぞれは正しくても「近づく?近づかない?」のように逆に聞こえることがある。そこで、ずかん全体を 5 つの**合言葉**(`keyword`)に整理し、各テーマがどの合言葉の場面かを一覧と再生画面にチップで示す。

| 合言葉 | 意味 | テーマ |
|---|---|---|
| 👀 見る(`look`) | もらう前・守る時に、ボールと相手と空いている所を見る | A4 もらう前に見る、B3 後ろへ走るタイミング、C2 両方を見る |
| 🏃 動いて受ける(`move`) | 相手のかげから出る・広がる・はなれてもどる | A1 顔を出す、A2 反対サイド、A3 キーパーから、B2 ワンツー、E1 ゴールキック、E2 スローイン |
| 🥅 ゴールへ向かう(`goal`) | しかける・引きつける・打つ・ゴール前へ入る | B5 ドリブルかパスか、B8 1対1、B7 2対1、B1 ゴール前へ、B9 打てる時はシュート、B4 つめる、E5 味方のコーナー |
| 🔄 すぐ切りかえる(`switch`) | 取られたら近くの人は取り返す・遠くの人はもどる、取ったら前を見る | D1・D2・D3 |
| 🛡️ ゴールを守る(`protect`) | 1 人が行き 1 人がカバー・外へ・おくらせる・しぼる | C6 しぼる、C1 カバー、C3 外へ、C5 おくらせる、E3 コーナーの守り、E4 キーパー |

**おすすめの順番**(`courseOrder`)は、U-10 の一般的な指導順(個人の判断 → 2〜3 人の関係 → 切りかえ → ゴール前 → 場面ごと)に合わせた。一覧の既定の並びにしている。値は `tools/scenario-src/groups.mjs` で管理する。

| ステップ | 順番 | テーマ |
|---|---|---|
| 1 まずはここから | 1〜9 | A4 もらう前に見る → A1 顔を出す → B5 ドリブルかパスか → B8 1対1でしかけよう → B7 2対1 → C6 しぼる → C1 1人が行く、1人がカバー → C3 外へ追い出そう → C5 おくらせる |
| 2 切りかえとゴール前 | 10〜18 | D1 すぐ取り返す → D2 取ったら前を見る → D3 もどる道 → B1 サイドからゴール前へ → B9 打てる時はシュート → B4 シュートの後につめる → B2 ワンツー → B3 後ろへ走るタイミング → C2 両方を見る |
| 3 場面ごとの動き | 19〜25 | A2 反対サイドへ → A3 キーパーから → E1 ゴールキック → E2 スローイン → E3 コーナーの守り → E5 味方のコーナー → E4 キーパーの立つ場所 |

C6(しぼる)は C1 の中央パターン(「3 番が中へしぼる」)より前に見せる。C3(外へ)の前に「1対1の守り方(構え)」を入れる案は、第 6 弾の残りの候補(9 章)で検討する。

第 5 弾のテーマを選んだ理由(2026-11-15 の見直し):
- 種類ごとの本数を比べると、**C(守る)が 6 本で最も少ない**。サッカーの守備の原則(寄せる・カバー・方向づけ・マーク・**おくらせる・バランス**)のうち、後ろの 2 つにあたるテーマがない。
- 攻撃の原則(幅・深さ・サポート・突破・フィニッシュ)はそろっているが、その前の**「受ける前に見る」**と、**数で勝っている時(2対1)の攻め方**がない。
- E3(相手のコーナーキック)はあるが、**味方のコーナーキック(攻める側)**がない。
- C5↔B7(2対1)、E3↔E5(コーナー)は**同じ場面を守る側・攻める側から見る組み合わせ**にして、「相手はこう考えている」まで伝える。

## 6. テーマごとの設計メモ(第 2 弾以降。作る時にパターンへ分ける)

記号: **問** = 問いかけ(`question`)、**ポ** = 今日のポイント(`keyPoint`)、S2〜S5 = ステップの流れ。選手番号は味方。相手は「相手の○番」と書く。

### A. ボールを前へ運ぶ

#### A1 パスコースに顔を出そう(`support-angle`)【第 1 弾・作成済み】
- **場面**:自陣右から中央。4 番がボールを持ち、相手 9 番がプレスに来る。
- **ねらい**:受け手が相手の「かげ」から出て、パスコースを作る(角度と距離)。旧案の A1(受ける場所)と A2(三角形)を統合した。
- **問**:4番が相手に追われている。6番はどこにいればパスをもらえるかな?
- **ポ**:相手のかげから出て、ボールを持つ人から見える場所に立とう!
- **◎**:S2 6番が相手 9 番のかげから横にずれ、4・6・7 で三角形 → S3 4番→6番 → S4 6番が前を向き、7番へ → S5 7番が前進してチャンス
- **×(1つ)**:6番が相手の真後ろ(かげ)に立ったまま → S3 4番は出しどころがなく横パス → S4 相手にカット → S5 自陣でピンチ
- **図示**:`passLane` の `blocked`(かげ)/`open`、`triangle`(お手本 S2〜S4)
- **注意**:B1 の「近づきすぎない」と矛盾しないよう、6番は「見える場所に動く」だけで、ボールに寄りすぎない距離(8〜10m)にする。

#### A2 反対サイドへ大きく(`switch-play`)【第 3 弾】
- **場面**:相手陣の右サイド。8番の周りに相手が集まっている。
- **ねらい**:混んでいる側から、空いている側へ展開する。
- **問**:右サイドに相手がたくさん集まってきた。どこがあいているかな?
- **ポ**:せまくなったら、広い反対サイドへボールを動かそう!
- **◎**:S2 7番が左サイドで大きく広がる → S3 8番→6番(下げる)→ S4 6番→7番(左へ)→ S5 7番が広いスペースで1対1
- **×**:7番もボールの近くに寄ってくる(サイドを変える先がない)→ S3 8番が細かいパスを続ける → S4 囲まれて奪われる → S5 カウンター
- **注意**:4年生のキック力では 30m 以上の一発のサイドチェンジは現実的でないため、**6番を経由した 2 本のパス**で描く。

#### A3 キーパーから始めよう(`build-from-keeper`)【第 3 弾】
- **場面**:味方 GK がボールをキャッチした直後。
- **ねらい**:DF がペナルティエリアの外に広がり、GK からつなぐ。
- **問**:キーパーがボールを取った。2番と3番はどこへ動けばいいかな?
- **ポ**:キーパーがボールを持ったら、左右に大きく広がろう!
- **◎**:S2 2番・3番がタッチライン近くへ広がる → S3 1番→2番 → S4 2番→7番 → S5 ハーフウェーラインをこえて前進
- **×**:2番・3番がゴール前に残ったまま → S3 1番は大きくけるしかない → S4 相手が拾う → S5 また守備になる
- **結末**:`outcomeTone: "miss"`(△ 残念…「相手ボールに…」)。無理に失点の危機を作らない。

#### A4 もらう前に周りを見よう(`scan-before`)【第 5 弾・作成済み】
- **場面**:自陣から中央。4 番が 6 番へパスを出す直前。6 番の後ろから相手 8 番が近づいている。
- **ねらい**:パスが来る前に周りを見て、受ける前に次のプレーを決めておく(体の向き)。
- **問**:4番からパスが来る。6番は、パスが来る前に何をすればいいかな?
- **ポ**:パスが来る前に、後ろと前を見ておこう!

- **追加機能**:`look` オーバーレイ(実装済み)。お手本は `look("h6", "a8")` で後ろを見た扇形(黄)、ミスは `look("h6", "ball", "bad")` でボールだけを見る扇形(赤)。扇形を出しているステップは選手の向き(三角)も見る先を向く。
- **注意**:ミスは「見なかった」の 1 つだけにする。受ける場所(A1)は good と bad で同じにして、A1 と区別する。

### B. ゴールをねらう

#### B1 サイドからゴール前へ(`side-attack-box-entry`)【作成済み】

#### B2 ワンツーで抜け出そう(`one-two`)【第 2 弾】
- **場面**:相手陣中央。7番がボールを持ち、前に相手 6 番。9番が近くにいる。
- **ねらい**:パスを出した後に止まらず走る(パス&ゴー)。
- **問**:7番は9番にパスを出した。そのあと7番はどうすればいいかな?

- **注意**:9番の受ける位置は 7番から 5〜8m(4年生のワンタッチパスで届く距離)。

#### B3 相手の後ろへ走るタイミング(`run-behind`)【第 1 弾・作成済み】
- **場面**:相手陣中央。6番がボールを持ち、9番が相手 DF ラインの近くにいる。
- **ねらい**:オフサイドにならない動き出し(相手 DF とそろってから、パスと同時に走る)。
- **問**:9番は、いつ相手の後ろへ走り出せばいいかな?
- **ポ**:相手の守る人とならんで待ち、パスが出る時に走り出そう!

- **×**:9番が早く走り出して DF より前で待つ → S4 6番→9番 → **オフサイド**の笛 → S5 相手ボールで再開(相手のフリーキック)
- **追加機能**:`offsideLine` オーバーレイ(実装済み)。
- **実装方針(決定)**:ミス側のこのパスに `ball.offside: true` を付ける(検証はこの明示がある時だけ通す)。Step 2〜4 で `offsideLine`(守備側=away)を表示し、9番がラインより前に出る様子を見せる。結末は `outcomeTone: "miss"`(△ 残念…相手ボールに)。

#### B4 シュートの後につめよう(`follow-the-shot`)【第 3 弾】
- **場面**:ペナルティエリア付近。9番がシュートを打つ。
- **ねらい**:シュートのこぼれ球に備えてゴール前へつめる。
- **問**:9番がシュートを打った!8番と7番はどうする?
- **ポ**:シュートが打たれたら、ゴール前につめよう!
- **◎**:S2 8・7番がゴール前へ走る → S3 9番のシュート → S4 キーパーがはじく → S5 8番が押しこむ
- **×**:8・7番がシュートを見ているだけ → S4 キーパーがはじく → S5 相手 DF が先に拾ってクリア(`outcomeTone: "miss"`)
- **注意**:ボールの動きに「はじく」がない(`motion` は持ち主の変化で表す)。キーパーがはじいたボールは `shot` → 次ステップで `steal`(相手)または `ground`(味方)として表現できるか要確認。

#### B5 ドリブルか、パスか(`dribble-or-pass`)【第 3 弾】
- **場面**:相手陣の左サイド。7番がドリブル中。
- **ねらい**:前が空いていればドリブル、相手が来たら空いた味方へ(判断)。**ドリブルそのものは否定しない。**
- **問**:7番はドリブル中。相手の4番が来た!どうすればいいかな?
- **ポ**:前が空いていたらドリブル、相手が来たら空いている味方を使おう!
- **◎**:S2 7番が空いたスペースをドリブル(◎吹き出し「空いてる!」)→ S3 相手 4 番が寄せる → S4 空いた 9 番へパス(2対1)→ S5 9番がシュート
- **×**:S2 はお手本と同じ(ドリブルは良い)→ S3 相手 4 番が来ても続ける → S4 2人にはさまれて奪われる → S5 カウンター
- **注意**:**S2 は good と bad で同じにして、ドリブル自体は良いプレーと伝える**。差は S3 の判断だけ。

#### B7 2対1は引きつけてからパス(`two-v-one`)【第 5 弾・作成済み】
- **場面**:相手陣の左サイド。7 番がボールを持ち、近くに 9 番。守る相手は 3 番だけ。
- **ねらい**:数で勝っている時は、守る人を自分に引きつけてから空いた味方へ出す(パスのタイミング)。C5 の裏返し。
- **問**:2人対1人だ!7番はいつパスを出せばいいかな?
- **ポ**:守る人を自分に引きつけてから、空いた味方へ出そう!
- **◎**:S2 7番が相手 3 番に向かってドリブル → S3 相手 3 番が 7番へ寄せる → S4 7番→9番 → S5 9番がフリーでシュート
- **×**:S2 7番が遠くからすぐ 9番へパス → S3 相手 3 番が 9番へ寄せる → S4 9番が囲まれる → S5 相手ボール(`outcomeTone: "miss"`)
- **注意**:B5(ドリブルか、パスか)との違いは「早すぎるパス」がミスの点。B5 の「続けすぎるドリブル」と対にして、`coachNote` で両方を説明する。

### C. ボールを取る・守る

#### C1 1人が行く、1人がカバー(`press-and-cover`)【第 1 弾・作成済み】
- **場面**:自陣左サイド。相手 8 番がドリブルで向かってくる。味方 2 番と 4 番が近い。
- **ねらい**:ボールに行く人(1人目)と、後ろで守る人(カバー)の役割分担。
- **問**:相手がドリブルしてきた。2番と4番はどう守ればいいかな?
- **ポ**:1人がボールに行ったら、もう1人はななめ後ろで守ろう!
- **◎**:S2 2番が寄せ、4番は2番のななめ後ろへ → S3 相手が 2番をかわす → S4 4番がすぐ寄せる → S5 4番がボールを取る
- **×**:2番と4番が同時にボールへ飛びこむ → S3 相手が 1 回のかわしで 2 人を抜く → S4 中央がガラ空き → S5 シュートを打たれる
- **注意**:B1 の「近づきすぎない」と区別するため、問いかけで「守る時の 2 人の役割」と明示する。

#### C2 ゴール前は、ボールと相手の両方を見る(`mark-and-ball`)【第 2 弾】
- **場面**:自陣右サイドから相手がクロスを上げようとしている。味方 3 番の近くに相手 9 番。
- **ねらい**:マークとボールの両方が見える体の向き・立ち位置。
- **問**:相手がクロスを上げそう。3番はどこに立てばいいかな?
- **ポ**:ボールと相手の両方が見える場所に立とう!
- **◎**:S2 3番が相手 9 番とボールを結ぶ線の内側(ゴール側)に立つ → S3 クロス → S4 3番が先にさわる → S5 クリアしてカウンター
- **×**:3番がボールだけを見て、相手 9 番が背中側に回る → S4 9番がフリー → S5 フリーでシュート
- **追加機能(任意)**:選手の「見ている方向」を扇形で表示できると分かりやすい。今の「向き(三角)」でも最低限は表現できる。

#### C3 外へ追い出そう(`show-outside`)【第 3 弾】
- **場面**:自陣中央寄り。相手 7 番がドリブルで中央へ入ろうとしている。
- **ねらい**:寄せる角度で、相手をタッチライン側(危なくない方)へ追い出す。C1 の発展。
- **問**:相手がゴールの方へ入ってきそう。2番はどっちから寄せればいいかな?
- **ポ**:ゴールの方(内側)をふさいで、外へ追い出そう!
- **◎**:S2 2番が内側から寄せる → S3 相手は外へ → S4 7番と 2 人ではさむ → S5 タッチライン際で奪う
- **×**:2番がまっすぐ寄せて内側が空く → S3 相手が中央へ → S4 中央からシュートコース → S5 シュート

#### C5 数で負けている時はおくらせる(`delay-outnumbered`)【第 5 弾・作成済み】
- **場面**:相手陣でボールを取られ、相手 9 番と 8 番が 2 人で運んでくる。味方は 4 番だけ(D3 でもどる味方がいる)。
- **ねらい**:数で負けている時は飛びこまず、2 人の間に立って時間をかせぎ、味方がもどるのを待つ。「ゴール近くで取られた時」(もとは D1 の 3 つ目のパターン。指導者レビュー CR-1 で、「すぐ取り返す」と逆に聞こえるためこのテーマへ移した)も含む。
- **問**:相手が2人、味方は4番だけ。4番はどうすればいいかな?
- **ポ**:1人で2人を守る時は、飛びこまずに味方を待とう!
- **◎**:S2 4番がななめに下がりながら 2 人の間に立つ → S3 相手はパスを出せず運ぶだけ → S4 もどった 6 番と 2 対 2 → S5 6番が取る
- **×**:4番がボールに飛びこむ → S3 横パスでかわされる → S4 相手 8 番がフリー → S5 キーパーと 1 対 1(ピンチ)
- **図示**:`passLane` の `blocked`(4番が消している中へのコース)、もどる 6 番の `arrow`
- **注意**:C1(1人が行く)と矛盾しないよう、問いかけで「1人で2人」の場面だと明示する。

#### C6 ボールの反対側はしぼろう(`tuck-in`)【第 5 弾・作成済み】
- **場面**:相手が自陣の右サイド(画面の右)でボールを持つ。ボールから遠い 2 番が左タッチライン近くにいる。
- **ねらい**:ボールから遠い守備者は、ゴール前の方へ動いて味方との間をせまくする(バランス)。
- **問**:ボールは右にある。遠くにいる2番はどこに立てばいいかな?
- **ポ**:ボールから遠い人は、ゴール前の方へ動こう!
- **◎**:S2 2番が 4番の方へ寄る → S3 相手が中へパス → S4 2番がカット → S5 カウンター
- **×**:2番が外に残る → S3 4番と 2番の間を通される → S4 ファーの相手がフリー → S5 シュート(ピンチ)
- **注意**:ライン全体の上げ下げ(7 章 C4)にはしない。「遠い 1 人の動き」に絞る。D3(もどる道)とは、すでに守備の形ができている点で区別する。

### D. 切りかえ

#### D1 取られたらすぐ取り返す(`counter-press`)【第 1 弾・作成済み】
- **場面**:相手陣の左サイド。7番が相手にボールを取られた瞬間(B1 のミス側の続きとして作れる)。
- **ねらい**:攻→守の切りかえ。近くの選手がすぐに寄せて取り返す。
- **問**:7番がボールを取られた!近くの7番と6番はどうする?
- **ポ**:取られたら、近くの人はすぐに取り返しに行こう!
- **◎**:S2 7番がすぐ追い、6番が前へのパスコースをふさぐ → S3 相手は苦しまぎれのパス → S4 6番がカット → S5 そのままシュート
- **×**:7番と6番が止まって見ている(◎/× 吹き出し「すぐ行く!」/「止まってる」)→ S3 相手が前を向いてパス → S4 カウンター 3対2 → S5 ピンチ
- **図示**:`passLane` の `blocked`(6番が消したコース)
- **注意**:B1 の「ボールに近づきすぎない」との違い(取られた瞬間の、近くの人)を `coachNote` で説明する。

#### D2 取ったら前を見よう(`counter-attack`)【第 2 弾】
- **場面**:自陣中央。4番が相手のパスをカットした瞬間。
- **ねらい**:守→攻の切りかえ。奪ったらまず前を見て、相手の守備がそろう前に攻める。
- **問**:4番がボールを取った!まず、どこを見ればいいかな?
- **ポ**:ボールを取ったら、まず前を見よう!
- **◎**:S2 4番が前を向き、9・8番が前へ走る → S3 4番→9番 → S4 9番→8番(3対2)→ S5 シュート
- **×**:4番が後ろの1番へパス(安全だが遅い)→ S3 相手の守備が戻る → S4 前にパスコースがない → S5 攻めのチャンスが消える(「チャンスが消えた…」)
- **注意**:ミスの結末は失点の危機ではなく「チャンスを逃す」ので `outcomeTone: "miss"`。**後ろへのパス自体は悪くない**ので、「前が空いている時は」と条件を付けて描く。

#### D3 取られたら戻る道(`recovery-run`)【第 3 弾】
- **場面**:相手陣でボールを取られ、相手がカウンターを始めた。遠くにいる 8 番と 3 番。
- **ねらい**:ボールから遠い選手の戻り方(ボールではなく、ゴールとボールの間へ)。D1(近い人)と対になる。
- **問**:ボールを取られた!遠くにいる8番はどこへ戻ればいいかな?
- **ポ**:遠くの人は、ボールではなく自分のゴールの方へ戻ろう!
- **◎**:S2 8番が自陣ゴールの方へまっすぐ戻る → S3 相手が中央へパス → S4 8番がコースに入る → S5 カット
- **×**:8番がボールを追いかけて横から走る → S4 中央がガラ空き → S5 シュート

### E. リスタート・キーパー

#### E1 ゴールキックの時の広がり方(`restart-shape`)【第 2 弾】
- **場面**:味方のゴールキック。
- **ねらい**:再開の時に団子にならず、広がってパスコースを作る。
- **問**:ゴールキックだ。みんなはどこに立てばいいかな?
- **ポ**:ボールが止まっている時こそ、広がってパスの道を作ろう!
- **◎**:S2 2・3番が左右に、6番が中央に広がる → S3 1番→3番 → S4 3番→8番 → S5 前進
- **×**:全員がボールの近くに集まる → S3 1番は近くの 4番へ → S4 相手がすぐ取る → S5 自陣でピンチ
- **注意(ルール)**:8人制では、ゴールキック時に相手がペナルティエリアの外で待つ・ハーフウェーラインまで下がるなど、**大会ごとにルールが違う**。相手は「ペナルティエリアの外」に置き、特定のローカルルールに依存しない配置にする。

#### E2 スローインは動いて受ける(`throw-in-movement`)【第 3 弾】
- **場面**:相手陣の左サイドで味方のスローイン(2番が投げる)。
- **ねらい**:受け手が一度離れてから戻り、マークを外して受ける。
- **問**:スローインだ。7番はどうすればマークを外せるかな?
- **ポ**:止まって待たずに、動いてマークを外そう!
- **◎**:S2 7番が一度前へ走ってから戻る → S3 2番→7番(フリー)→ S4 7番が前を向く → S5 前進
- **×**:7番が止まって待つ(相手がぴったりつく)→ S3 投げる先がなく、無理に投げる → S4 相手に取られる → S5 カウンター
- **注意(ルール)**:地域・大会によっては**キックイン**を採用している。画面では「スローイン」とし、`coachNote` でキックインでも同じ考え方と補足する。ボールは X=0(タッチライン上)から始める。

#### E3 コーナーキックの守り方(`corner-defense`)【第 3 弾】
- **場面**:相手のコーナーキック(右から)。
- **ねらい**:ボールに集まらず、ニア・ファー・相手の得点役に役割を分けて立つ。
- **問**:相手のコーナーキック。みんなはどこに立てばいいかな?
- **ポ**:ボールだけを見ないで、ゴールの前の場所と相手を守ろう!
- **◎**:S2 4番がニア、3番がファー、9番も戻って相手 9 番につく → S3 クロス → S4 4番がクリア → S5 9番が拾ってカウンター
- **×**:みんながボールの近くに集まり、ファーが空く → S4 ファーの相手がフリー → S5 シュート
- **注意**:8人制のコーナーは人数が少ないので、全員を固定しない(1人は前に残す)形で描く。

#### E4 キーパーの立つ場所(`keeper-position`)【第 3 弾・追加機能の後】
- **場面**:相手が右サイドからゴールに向かってくる。
- **ねらい**:ボールの位置に合わせて、ゴールの両はしとボールを結んだ線の真ん中に立つ。
- **問**:相手がボールを右に運んだ。キーパーはどこに立てばいいかな?
- **ポ**:ボールが動いたら、キーパーも動こう!
- **◎**:S2 1番がボールに合わせて右・前へ → S3 シュート → S4 1番がキャッチ → S5 すぐにパスで攻撃へ
- **×**:1番がゴールの真ん中に立ったまま → S3 ニアへシュート → S4 届かない → S5 失点の危機
- **追加機能**:`shotCone` オーバーレイ(実装済み)。`from: "ball"`, `goal: "home"`, `centerLine: true` で、ボールと両ポストを結ぶ三角形と、キーパーが立つ目安の線を描く。

#### E5 味方のコーナーキック(`corner-attack`)【第 5 弾・作成済み】
- **場面**:味方のコーナーキック(右から、8 番がける)。
- **ねらい**:ニア・ファー・こぼれ球の場所に分かれて入り、後ろにも残る。E3(守る側)の裏返し。
- **問**:味方のコーナーキックだ。みんなはどこに入ればいいかな?
- **ポ**:ニア・ファー・こぼれ球の場所に分かれよう!
- **◎**:S2 9番がニア、7番がおくれてファー、6番がペナルティエリアの外 → S3 クロス → S4 相手がはね返す → S5 6番が拾ってシュート
- **×**:みんながニアに集まる → S3 クロス → S4 相手がクリア → S5 こぼれ球も相手が拾う(`outcomeTone: "miss"`)
- **注意**:8 人制のコーナーは人数が少ないので、4・3 番は後ろに残してカウンターにそなえる(E3 の「1 人は前に残す」と対になる)。
