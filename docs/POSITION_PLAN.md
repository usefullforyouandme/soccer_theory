# ポジション別のシチュエーション(案)

作成: 2026-11-16 / 状態: **確定(2026-11-16。6 章の 4 点はすべておすすめの案に決定)**。一覧の画面は BL-22 で作成済み、★ は BL-23

## 1. ねらい

これまでのずかんは「原則(テーマ)」から入る作りになっている(例: 1人が行く、1人がカバー)。でも 4 年生は試合で「きょうは右MF」のようにポジションを任されるので、知りたいのは **「自分のポジションでは、どんな場面で、何をすればいい?」** の方になる。

そこで、**ポジションを入口にした新しいトピック**を作る。
- ポジションごとに、**役割の解説**(ひとことで言うと / 攻める時 / 守る時 / 切りかえの時 / よくあるミス)を書く。
- そのポジションの子が試合でよく出会う**シチュエーション**を、攻撃・守備・切りかえ・リスタートに分けて並べる。
- 今あるシナリオで描ける場面は**今あるシナリオを割り当てる**。ない場面だけ新しく作る(★)。

## 2. ポジションの分け方(案)

8 人制の基本の形 3-3-1 にそろえ、**左右は同じ考え方なのでまとめて 6 区分**にする(画面のポジション表示「左MF」「真ん中DF」と同じことばを使う)。

| 区分 | 背番号(3-3-1) | 2-3-2 の時 |
|---|---|---|
| ① キーパー(GK) | 1 | 同じ |
| ② 真ん中DF | 4 | いない(2・3 の 2 人で真ん中も守る) |
| ③ サイドDF(左DF・右DF) | 2・3 | 2・3(真ん中寄りに立つ) |
| ④ 真ん中MF | 6 | 6 |
| ⑤ サイドMF(左MF・右MF) | 7・8 | 7・8 |
| ⑥ FW | 9 | 9・10(2 人) |

2-3-2 は、各ポジションの解説に「2-3-2 の時のちがい」を 1〜2 行で足す(シナリオは 3-3-1 を基本にする)。

## 3. ポジションごとのシチュエーション

表の見方: ✅ = 今あるシナリオを割り当てる / ★ = 新しく作る候補(仮の名前)。

> **✅ の割り当ては `src/positions.ts` が正**(この章の ✅ は最初の案)。BL-22 で各シナリオのお手本の説明文と `focus` に出る選手を集計し、主役のポジションに合わせて直した(例: C5 ゴール前の主役は 4 番ではなく 3 番なのでサイドDF へ、E1 前から来るは 3 番・8 番が主役なのでサイドDF へ、A1 中央の主役は 6 番なので真ん中MF へ)。

### ① キーパー(GK)— 「最後の守り」で「攻撃のスタート」
- 攻める時: ボールを持ったら、空いている方へすぐ出す。
- 守る時: ボールとゴールの真ん中に立つ。DF の後ろが空いたら先にさわる。
- よくあるミス: ゴールラインにはりついたまま / 取ったら急いで相手のいる方へけってしまう。

| 場面 | シチュエーション | シナリオ |
|---|---|---|
| 守る | シュートを打たれそうな時、どこに立つ? | ✅ E4 右から・正面から |
| 守る | 相手 DF の後ろへ長いボールが来た! | ★ GK-1 飛び出して先にさわる(カタログ 9 章の候補) |
| 守る | 相手と 1 対 1 になった! | ★ GK-2 早く倒れずに、体を大きくして待つ |
| 攻める | ボールをキャッチした。だれに出す? | ✅ A3 キャッチした時・FW が近い時 |
| 攻める | 味方 DF が追われて、後ろにもどしてきた | ★ GK-3 パスを受けられる場所に動く(手は使えない) |
| リスタート | ゴールキック | ✅ E1(けるのはキーパー。出しどころの判断) |

### ② 真ん中DF(4 番)— 「ゴールの前の、まんなかのカベ」
- 守る時: いちばんゴールに近い所を守り、味方がぬかれた時のカバーをする。
- 攻める時: 追われたら無理をせず、空いている味方やキーパーを使う。
- よくあるミス: ボールに飛びこんでぬかれる / ゴール前でけり返す方向に迷う。

| 場面 | シチュエーション | シナリオ |
|---|---|---|
| 守る | 前の味方がボールに行った。自分は? | ✅ C1 中央(後ろでカバー) |
| 守る | 相手が真ん中からスルーパスをねらっている | ✅ C2 中央からのスルーパス |
| 守る | 1人で2人を守ることになった | ✅ C5 ゴール前で 2 対 1 |
| 守る | 相手 FW へ縦パスが来た。前でさわる?後ろで待つ? | ★ CB-1 取れる時は前で取る・取れない時は前を向かせない |
| 守る | ゴール前でこぼれ球。どこへけり出す? | ★ CB-2 迷ったら外へ・遠くへ(真ん中へ返さない) |
| 攻める | ボールを持ったら相手 FW が来た | ✅ A1 中央で 4 番が追われた時(助ける側の動きも見られる) |
| リスタート | 相手のコーナーキック | ✅ E3 右から |

### ③ サイドDF(2 番・3 番)— 「サイドを守り、反対の時は中へ」
- 守る時: ボールがこちらのサイドなら外へ追い出す。反対のサイドならゴール前へしぼる。
- 攻める時: 広がってパスを受け、前の味方へつなぐ。
- よくあるミス: ボールが反対サイドなのに外で見ている / 相手に飛びこんでぬかれる。

| 場面 | シチュエーション | シナリオ |
|---|---|---|
| 守る | 相手がこちらのサイドをドリブルしてきた | ✅ C3 ゴールに近いサイドで / ✅ C1 サイド |
| 守る | ボールが反対のサイドにある時 | ✅ C6 相手が右サイドにいる時 |
| 守る | サイドで相手と 1 対 1(構え方) | ★ SB-1 体をななめにして外へ向かわせる(9 章「1対1の守り方」) |
| 攻める | 味方に追われてボールが来た | ✅ A1 サイドで 2 番が追われた時 |

### ④ 真ん中MF(6 番)— 「チームのまんなかで、つなぐ人」
- 攻める時: ボールを持つ味方から見える所に顔を出し、もらう前に周りを見る。
- 守る時: 真ん中を通らせない。ボールを取られたらすぐ取り返す。
- よくあるミス: ボールに寄りすぎて味方と重なる / 見ないで受けて後ろから取られる。

| 場面 | シチュエーション | シナリオ |

| 攻める | 後ろからパスが来る。もらう前に何をする? | ✅ A4 中央で受ける時 |

| 攻める | 片方のサイドがせまくなった | ✅ A2 右サイドがせまい時 |
| 攻める | 相手と相手の間で受けて前を向く | ★ CM-1 間で受ける(9 章の候補。A1・B2 と重ならないよう、ミスは「相手の前で受ける」) |

- よくあるミス: 早く走り出してオフサイド / パスに逃げてシュートを打たない / 取られたら歩いてしまう。

## 5. 見せ方(案)

- 一覧の並びかえに 3 つ目の「**ポジションから選ぶ**」を足す(今は「おすすめの順番」「種類ごと」)。
- ポジションごとに**解説カード**を 1 枚出す: ミニピッチでそのポジションの担当エリアをぬり、役割のひとこと・攻める時・守る時・よくあるミスを 3〜4 行で書く。その下に場面ごとのシナリオのカードを並べる。
- 再生画面ではそのポジションの子を黄色いリングで目立たせ、ポジション表示を最初からオンにする(どの丸が自分か分かるように)。
- データは `tools/scenario-src/positions.mjs`(`groups.mjs` と同じ考え方)に、ポジションごとの解説とシナリオ id の並びをまとめる。シナリオの JSON(スキーマ)は変えずにすむ見込み。

## 6. 決めたこと(2026-11-16)

ユーザーの決定: 4 点ともおすすめの案で進める。
- 形は (A)。区分は 6 区分。
- ★ は 11 場面にする。FW-1(ポストプレー)と GK-3(バックパス)は 4 年生には早いので、カタログ 7 章の高学年向けストックに回した。
- 先に画面を今あるシナリオだけで作り(BL-22)、★ は 1 ポジションずつ足す(BL-23)。
- データは `tools/scenario-src/positions.mjs` ではなく、画面だけで使うので `src/positions.ts` に置いた(シナリオの JSON とスキーマは変えていない)。

以下は決める前の選択肢(記録)。

1. **形**: (A) 今あるシナリオの割り当て+足りない場面だけ新しく作る【おすすめ】/ (B) すべて新しく作る(重なりが増え、本数が倍以上になる)。
2. **区分**: 左右をまとめた 6 区分【おすすめ】/ 左右も分けた 8 区分。
3. **★の候補**: 13 場面のうち、入れる・外すもの。4 年生には早いもの(例: FW-1 ポストプレー、GK-3 バックパス)は 7 章の高学年向けストックに回す手もある。
4. **進め方**: まず画面(ポジションから選ぶ一覧+解説カード)を今あるシナリオだけで作り、その後に★を 1 ポジションずつ足す【おすすめ】/ ★を先に作る。
